## D-001. 다른 Windows 계정이나 원격에서 엔진에 접근해도 되는가 (M0)

- **질문:** 같은 PC의 다른 Windows 계정, 다른 PC(SMB), SSH로 들어온 세션에서 엔진(`vuyro` CLI 포함)을 쓸 수 있어야 하는가?
- **고른 기본값:** 막는다. 엔진 파이프는 엔진을 띄운 사용자만 열 수 있고, 네트워크 로그온은 같은 사용자라도 거부한다.
- **이유:** MVP는 "내 로컬에서만 도는 앱"이다(PRD 비목표). 엔진 명령으로 에이전트를 실행할 수 있으므로 열어 둘 이유가 없다.
- **영향 범위:**
  - SSH로 이 PC에 들어와 `vuyro` CLI를 쓰는 사용 방식은 막힐 수 있다. 엔진 옵션(`rejectRemote: false`)으로 풀 수 있게 해 두었다.
  - 같은 PC의 관리자는 기술적으로 막을 수 없다.
