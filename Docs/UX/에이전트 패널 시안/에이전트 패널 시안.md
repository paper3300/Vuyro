## 패널 공통 구성

- **범위 선택:** 티켓 / 프로젝트 / 관제실. 지금 보고 있는 화면이 자동으로 컨텍스트에 들어간다.
- **`@` 컨텍스트:** 티켓, 노드, 산출물을 직접 지정한다.
- **권한 3단계:** 질문만 / 실행 전 확인 / 자동.
- **"확인한 것" 목록:** 에이전트가 실행한 명령을 그대로 보여준다.
- **작업 제안 카드:** 실행·수정 버튼. 이미 실행한 작업에는 되돌리기 버튼.
- **규칙 저장 제안:** 같은 처리가 반복되면 자동 규칙으로 바꾼다. Archon의 "반복되는 실패에는 handler" 아이디어를 가져왔다.
- **대화별 토큰·비용 표시.**

## 설계 원칙

- **화면의 모든 동작은 같은 명령 API를 거친다.** 예: `vuyro node config`, `vuyro run end-turn`.
  - 사람이 버튼으로 하는 일과 에이전트가 하는 일이 같은 경로로 실행되고, 같은 작업 기록에 남는다.
  - 에이전트는 이 명령을 CLI나 MCP로 호출한다. `vuyro artifact add` 방식을 툴 전체로 넓힌 것이다.
- **비용이 들거나 되돌릴 수 없는 명령은 자동 모드에서도 확인을 받는다.**

## 소스 파일에 대해

- `.dc.html`은 디자인 캔버스 전용 형식이다. 브라우저에서 바로 열면 제대로 보이지 않는다.
- 화면을 보려면 위 캔버스 링크를 연다. 이미지가 필요하면 캔버스의 Export 메뉴를 쓴다.
- 실제 앱을 구현할 때 레이아웃, 색상, 예시 데이터를 참고하는 용도다.
